# 猫カフェ Webページ

## 概要

架空の猫カフェを想定して、HTML・CSSを使用して作成したWebページです。

## 使用技術

* HTML
* CSS

## 工夫した点

* モノトーンを基調とし、大理石の素材を取り入れることで、高級感のあるデザインに仕上げました。
* 余白、文字の配置などを調整し、上品で見やすいレイアウトを意識しました。
* 猫カフェの魅力が伝わるよう、写真や各コンテンツの配置を工夫しました。
* Webページに使用する画像は、生成AIの画像生成機能を活用して制作しました。
* PCだけでなくスマートフォンでも見やすいよう、レスポンシブデザインに対応しました。
* スマートフォン表示ではハンバーガーメニューを実装し、限られた画面幅でもレイアウトが崩れないよう調整しました。
